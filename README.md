# Real Estate Price Prediction
This project develops machine learning models to predict residential property prices using structured housing data.

## Techniques Used
- Data preprocessing
- Feature engineering
- Multiple Linear Regression
- Random Forest Regression
- Gradient Boosting

## Tools
Python, Pandas, Scikit-learn, Matplotlib

## Overview
The project explores relationships between housing characteristics and property prices and evaluates several regression models to determine the most accurate approach.
